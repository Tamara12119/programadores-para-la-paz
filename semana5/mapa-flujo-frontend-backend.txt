Completa el flujo con tus palabras.

1. Frontend

¿Qué parte del proyecto corresponde al frontend?

Respuesta: Es la cara visible de la página, todo lo que los vecinos pueden ver y tocar en el navegador, como los botones, los colores, los formularios y la estructura de las tarjetas de los mensajes.

2. Backend

¿Qué parte del proyecto corresponde al backend?

Respuesta: Es la parte interna que funciona detrás de escena en el servidor con Node.js. Se encarga de procesar las peticiones, manejar las rutas y organizar la información oculta que el usuario no ve directamente.

3. API propia

¿Qué rutas expone la API propia del proyecto?

Respuesta: Expone las rutas locales que creamos para organizar los datos del sitio, que son /api/mensajes, /api/calendario y /api/resumen.

4. Datos

¿Qué archivos JSON usa el backend para responder?

Respuesta: El backend lee y saca la información de los archivos mensajes.json y calendario-editorial.json que están guardados en la carpeta data.

5. Consulta desde frontend

¿Qué función de JavaScript se usa para consultar la API?

Respuesta: Se usa la función fetch pasándole como argumento la ruta de la API a la que queremos conectarnos.

6. Espera de respuesta

¿Qué palabras se usan para esperar la respuesta del servidor?

Respuesta: Se usan las palabras clave async al declarar la función y await justo antes del fetch para congelar el código hasta que el servidor responda.

7. Conversión de respuesta

¿Qué hace respuesta.json()?

Respuesta: Agarra los datos crudos que devuelve el servidor y los transforma en un formato de objeto de JavaScript que el código del frontend puede entender y recorrer fácilmente.

8. Render dinámico

¿Qué significa mostrar datos dinámicamente en el tablero?

Respuesta: Significa que la página ya no tiene textos fijos escritos a mano, sino que las tarjetas se construyen solas en la pantalla usando la información real y fresca que llega desde la API en ese instante.

9. Prueba

¿Cómo verificaste que la información del tablero coincide con la API?

Respuesta: Abrí la ruta de la API en el navegador para ver los datos puros y luego revisé que en el tablero de la interfaz aparecieran exactamente los mismos avisos con las mismas palabras y sectores.

10. Propósito comunitario

¿Cómo ayuda esta integración a mantener información comunitaria actualizable?

Respuesta: Ayuda muchísimo porque permite que la cartelera cambie al instante. Cada vez que haya una nueva alerta o reunión en el barrio, solo se actualizan los datos del servidor y la página de los vecinos mostrará la información nueva automáticamente sin necesidad de volver a programar el sitio web.
