9. Explica con tus palabras qué significa fast-forward:
Respuesta: Significa que Git actualiza tu rama moviendo la "línea del tiempo" directamente hacia adelante porque no hay conflictos ni cambios intermedios que se crucen. Es como adelantar una película hasta el punto más reciente de forma directa y limpia.

10. ¿Por qué no se debe trabajar directamente en main?
Respuesta: Porque main es la rama donde está el código limpio y final que funciona. Si trabajamos directo ahí, podemos dañar el proyecto general, causar conflictos con los cambios de los profesores o borrar el trabajo de otros por accidente. Es mejor hacer todo en nuestra propia rama y probar que funcione primero.

11. Comando usado para revisar cambios al final:
Respuesta: git status

12. Comando usado para agregar cambios:
Respuesta: git add .

13. Comando usado para crear commit:
Respuesta: git commit -m "Mensaje descriptivo de los cambios"

14. Comando usado para publicar tu rama:
Respuesta: git push origin marien_segura
